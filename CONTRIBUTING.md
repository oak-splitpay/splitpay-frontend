# Contributing to SplitPay Frontend 💸

Thank you for contributing to the SplitPay web application!

## 🔗 Repository Ecosystem
- **Frontend dApp (This Repo)**: `oak-splitpay/splitpay-frontend`
- **Smart Contract & Backend API**: [`oak-splitpay/splitpay-backend-contract`](https://github.com/oak-splitpay/splitpay-backend-contract)

## 🛠️ Development Setup

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Run production build & lint checks
npm run build
```

## 🌊 Contribution Scope
- Frontend tasks: UI components, Tailwind CSS styling, Freighter wallet UX, QR code invoice modals, mobile responsiveness, error banners.
- Contract/backend tasks belong in [`splitpay-backend-contract`](https://github.com/oak-splitpay/splitpay-backend-contract).
- Run `npm run build` before opening a pull request to ensure zero TypeScript and lint errors.
